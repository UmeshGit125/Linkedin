# .ai: rules for any AI working on this project

This folder is committed to GitHub. It tells an AI how to work here. `knowledge/` (next to it) is private and never pushed.

Read in this order:
1. `rules.md`: how to work with Umesh (plain-language approvals, frontend lock, secrets, safety).
2. `decision-checklist.md`: what to check before making any decision or change.
3. `architecture.md`: structure of the project and what each file owns.
4. `github-push.md`: what must be true before any commit or push.
5. `knowledge-upkeep.md`: how to update the private `knowledge/` files after every change.

If two files disagree, the stricter rule wins. If a rule blocks the task, stop and ask Umesh.
